Forward the signing supervisor's isolated `CODEX_HOME` to the read-only Codex reviewer only. The encoder records that value when it attaches to the signing broker, and no caller or ambient value can set it. Redact Codex auth tokens, verbatim and JSON-escaped, from reviewer and generation output before the encoder returns, stores or logs that output. Generation now deletes Codex's raw last-message file after reading it.
In Codex subscription mode, the apply-signer launcher now refuses a non-empty ambient `CODEX_HOME`, `OPENAI_API_KEY` or `CODEX_API_KEY` before it reads the signing key.
When the provisioner starts from an already-provisioned Python runtime, it now removes the Git broker, runtime attestation and reviewed RuleSpec records it copied from that runtime. Before this fix, its broker install refused to overwrite the copied broker, and copying fresh records failed on the copied directory. The provisioner publishes a fresh attestation and copies fresh records only when it provisions the encoder; otherwise the new runtime has neither, and apply refuses it.
Repair extraction now prefers each source lane's verified retained rejected candidate over a live pair that a later failed model call left behind. It rejects an incomplete or invalid retained export rather than falling back to stale files.
