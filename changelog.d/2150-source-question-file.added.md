Add question files to `axiom-encode compare-sources` (`--question <file>`, format `axiom-source-question/v1`, #2150): several documents (statute, regulation, federal or state guidance) that answer one question. The file states the canonical facts and constraints once and gives each answer its own input map and metadata (`document_type`, `jurisdiction`, `corpus_citation_path`, optional effective dates). The step expands the file into every pair of answers, runs the unchanged pair compare on each, and writes one conflict record per pair plus a summary record. Witness groups gain a `conditions` field: the facts that only one side reads, with the value they have in every witness of that direction. The pair link format stays valid; a link fact that is only part of a derived input no longer needs an input of its own. No RuleSpec format change and no module edit. Question files live in `<jurisdiction>/questions/` with the suffix `.question.yaml`; `_rulespec_module_paths` and the SNAP readiness scan skip exactly those files, so they are never treated as modules, and a `.question.yaml` file in a module root is refused.
