For federal CFR units only (`us/regulation/<title>/<part>/<section>...`), both encoder prompt copies insert one rule after the cross-reference defer rule: when the citing phrase names the State or the agency as the actor that sets a value (establishes, elects, specifies, sets, selects or chooses) and no copied module exports it, the encoder encodes the branch with that value as a root `inputs` entry (with `entity`, `dtype`, `period`, `unit` for money and a `description` naming the provision; the cited module's input identifier when it has one) instead of deferring it. Every number, percentage of the Federal poverty level and dollar amount stated by the source or a cited federal provision stays a literal. Prompts of all other units are byte-identical to before. Encoder prompt version 6 to 7.
