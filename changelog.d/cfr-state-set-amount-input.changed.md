For federal CFR units only (`us/regulation/<title>/<part>/<section>...`), both encoder prompt copies insert one rule after the cross-reference defer rule. It covers a value the source applies from another provision when no copied module exports it and either the citing phrase names the State or the agency as the actor that sets it (establishes, elects, specifies, sets, selects, chooses), or the phrase cites a provision whose copied module takes that value as a local input and exports no rule for it. The encoder then encodes the branch with the value as a root `inputs` entry (with `entity`, `dtype`, `period`, `unit` for money and a `description` naming the provision; the cited module's input identifier in the second case) instead of deferring it; the rule takes precedence over the sibling carve-out defer rule for these units. Every number, percentage of the Federal poverty level and dollar amount stated by the source or a cited federal provision stays a literal, and federal limits on what the State may set are rules about the State plan. Prompts of all other units are byte-identical to before. Encoder prompt version 6 to 7. New local A/B tool `scripts/check_state_set_inputs.py` checks every new input of a candidate (root or implicit): a description naming a provision, an actor or cited-module trigger, no same-named rule in the RuleSpec root, and the cited paragraphs' dollar and FPL literals in the formulas.
