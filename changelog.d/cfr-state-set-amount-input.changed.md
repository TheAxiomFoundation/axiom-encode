For federal units of 42 CFR part 435 only (a positive allow-list, `CFR_STATE_SET_AMOUNT_PARTS`; `us/regulation/42/435/<section>...`), both encoder prompt copies insert one rule after the cross-reference defer rule. It covers an amount the source applies when no copied module exports it and the unit's own source text attributes the amount to the State in one of exactly two forms: the text names the State, the State agency or the agency as the actor of a verb of a closed list (establishes, sets, elects, specifies, selects, chooses, determines ... in its State plan), or the text names a level in effect on a stated calendar date under the State's own plan (the State's AFDC payment or income standard, the Medicaid State plan or a waiver of it). Each State-set input needs its own source phrase in which that amount is the object of the verb (or the dated level), and its name contains the words of that amount's noun phrase (qualifiers may be added); when the phrase defines the amount from another quantity, only the State-chosen parameter can be the input. No other wording qualifies, so an amount that a federal statute, regulation, agency or formula sets is never a State-set input; the encoder imports it from a copied module of the cited provision, or defers that branch with a reason that names the exact federal provision the source cites (not a description of the amount). For an accepted amount, and for no other value, the rule names the existing rules it narrows (no local cross-reference input for a deferred cited file, no `section_...` placeholder input, no local cross-reference fact when context lacks the export, defer on a deferred sibling). The encoder then encodes the branch with the value as a root `inputs` entry (with `entity`, `dtype`, `period`, `unit` for money and a `description` naming the provision), emits the `source_relation.type: delegates` record, and cites the qualifying source phrase word for word in a proof atom. Every number, percentage of the Federal poverty level and dollar amount stated by the source or a cited federal provision stays a literal, and federal limits on what the State may set are rules about the State plan. Prompts of all other units, also other CFR parts, are byte-identical to before. Encoder prompt version 6 to 7. New local A/B report aid `scripts/check_state_set_inputs.py` (not a gate; a person reads its rows; `--unit` is required and must equal the module's `corpus_citation_path`). It lists every new input of a candidate in two tables: State-set amount inputs (checked) and fact inputs (not checked). Checks: the unit is on the allow-list, a description naming a provision, every proof excerpt verbatim in the unit source, a trigger that binds one source span to one input (the input's name contains the words of the head noun phrase that is the object of the State actor's verb, or of the dated plan level), a `delegates` source relation, no same-named rule in the RuleSpec root, and every dollar amount, percentage and word fraction of the unit source as a number in the formulas. A WARN line lists name words that are not in the bound excerpt. The last line is `state_set_inputs=<n> failures=<n> warnings=<n>`. The tool exits 2 on a missing path, unparsable YAML, a wrong shape, an empty RuleSpec root, or a module whose `corpus_citation_path` is missing or is not the unit.
