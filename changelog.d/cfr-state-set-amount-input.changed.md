For federal units of 42 CFR part 435 only (a positive allow-list, `CFR_STATE_SET_AMOUNT_PARTS`; `us/regulation/42/435/<section>...`), both encoder prompt copies insert one rule after the cross-reference defer rule. It covers an amount the source applies when no copied module exports it and the unit's own source text attributes the amount to the State in one of exactly two forms: the text names the State, the State agency or the agency as the actor of a verb of a closed list (establishes, sets, elects, specifies, selects, chooses, determines ... in its State plan), or the text names a level in effect on a stated calendar date under the State's own plan (the State's AFDC payment or income standard, the Medicaid State plan or a waiver of it). No other wording qualifies, so an amount that a federal statute, regulation, agency or formula sets is never a State-set input; the encoder imports it or defers that branch. For an accepted amount, and for no other value, the rule names the existing rules it narrows (no local cross-reference input for a deferred cited file, no `section_...` placeholder input, no local cross-reference fact when context lacks the export, defer on a deferred sibling). The encoder then encodes the branch with the value as a root `inputs` entry (with `entity`, `dtype`, `period`, `unit` for money and a `description` naming the provision), emits the `source_relation.type: delegates` record, and cites the qualifying source phrase word for word in a proof atom. Every number, percentage of the Federal poverty level and dollar amount stated by the source or a cited federal provision stays a literal, and federal limits on what the State may set are rules about the State plan. Prompts of all other units, also other CFR parts, are byte-identical to before. Encoder prompt version 6 to 7. New local A/B tool `scripts/check_state_set_inputs.py` checks every new input of a candidate (root or implicit, formula function names excluded): the unit is on the allow-list, a description naming a provision, a numeric value, every proof excerpt verbatim in the unit source, a trigger from a verified excerpt only (actor or plan-level, recorded per input), a `delegates` source relation, no same-named rule in the RuleSpec root, and the cited paragraphs' dollar and FPL literals in the formulas. The tool exits 2 on a missing path, unparsable YAML, an empty RuleSpec root or a module without `corpus_citation_path`.
