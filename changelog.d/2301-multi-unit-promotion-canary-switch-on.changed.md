`MULTI_UNIT_PROMOTION_ENABLED` is `True` for the hosted canary of the multi-unit promotion lane (#2301). A signing run can only be a run of `main`, so the canary cannot run with the switch off. A dispatch without `units` is a single-unit promotion and is unchanged; nothing dispatches a batch by itself. `docs/reviewed-pr-promotion.md`, "The hosted canary", has the three batches, the pass rule, the stop rule and the rollback.
