Every YAML document the encoder re-serializes now goes through a YAML 1.2-safe dumper, so strings that the engine's YAML 1.2 reader would treat as numbers, booleans or null (for example `1e5`, `+.5`, `0E0`) stay quoted. Re-dumping existing modules can change quote style (`'1356'` becomes `"1356"`) without changing parsed data; apply manifests hash the bytes written to disk, so signed modules are unaffected.
