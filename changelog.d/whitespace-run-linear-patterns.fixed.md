Make 18 regular expressions on the interval parser's path linear in a run of spaces. The parser matched the raw gap between an amount and its parenthetical restatement ("5 dollars ($5)") with two `\s*` runs side by side whenever the unit was absent, so a long run of spaces that did not end in "(" backtracked quadratically. Seventeen other patterns on the same path had the same shape: five more in the interval parser, ten in the numeric extractor and two in the definition matcher of the bare-outline mask that the extractor's cleanup runs. Two of them, the value-bearing table row and the definition header, backtracked cubically in an indented line's leading spaces. Each rewrite leaves one way through a run of spaces and matches the same text, with the same spans and groups, as the pattern it replaces.
