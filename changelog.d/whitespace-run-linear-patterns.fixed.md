Keep the interval parser and the shared numeric extractor linear in a run of spaces. The interval parser matched the raw gap between an amount and its parenthetical restatement ("5 dollars ($5)") with two `\s*` runs side by side whenever the unit was absent, so a long run of spaces that did not end in "(" backtracked quadratically. Thirteen other patterns on the same path had the same shape: five more in the interval parser and eight in the numeric extractor, one of them cubic in an indented line's leading spaces. Each rewrite carries the whitespace after an optional item inside that item's group, and matches the same text, with the same spans and groups, as the pattern it replaces.
