The signed promotion lane can admit several new units in one candidate pull request and sign them in one run (#2301), switched off. `MULTI_UNIT_PROMOTION_ENABLED` in `reviewed_pr_admission.py` is `False`. With it on, a dispatch that names every unit of the candidate (`units` in the promotion wrapper) is admitted only when the list equals the pull request's change set of at most `MAX_PROMOTION_UNITS` (6) complete new primary/companion pairs; `promote-reviewed-candidate` then validates every unit before the first signature and writes one signed manifest per unit, in the form of a single-unit promotion, in one transaction or none.
