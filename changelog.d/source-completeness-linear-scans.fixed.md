Source-completeness deferral-reason clause lookups and per-branch scans are near-linear. A reason's clause and separator stops are computed once, its citation occurrences are grouped by key, and an analysis indexes its branches by path and position and decides each branch path against its frozen deferral set once. On main, a reason with many `section N` clauses grew about 4x per doubling and an outline of many branches about 3-4x. The generation coverage index uses the same indexes. They live for one analysis, are read only by the thread running it, and are dropped when it ends; branches or questions whose fields lack the types recognition gives them keep the original scans. Every helper keeps its original filter, so no verdict changes; differential tests pin results to the previous scans, and growth tests bound CPU time per doubling.
