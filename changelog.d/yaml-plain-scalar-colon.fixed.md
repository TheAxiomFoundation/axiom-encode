Quote a generated `source:` or `excerpt:` value whose `:` ends the line (for example "one of the following:") in the eval-time artifact repair, not only at `--apply`, so a local encode no longer fails its YAML parse on a list lead-in. A repair-overlay retry still parses its new output before this repair runs. The repair adds quotes only, refuses multi-line or non-plain values, and writes only when each quoted line reads back as its exact text. The eval result records the lines that the repair quoted in that invocation, and signed eval-suite verdict evidence includes the record, so an edit to it fails suite admission.
