Add a switched-off rule that lets the reviewed-PR promotion lane admit a candidate whose base is an older head of RuleSpec `main` (`BASE_ADVANCE_ADMISSION_ENABLED`, `False`). With the switch on, `main` may be ahead of the base when the base is on the first-parent history of `main` (at most 20 commits back), every non-plumbing file of the base is the same object at the head of `main`, every other difference is a new module, companion or signed manifest in a jurisdiction unrelated to the units, and no new path collides with the candidate's units. The publication step then writes the last proven head of `main` to the run summary and the lane pull request. With the switch off every read, record and error is unchanged. `docs/reviewed-pr-promotion.md`, "A candidate on an older main base".
