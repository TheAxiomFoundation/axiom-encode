Stop escaping the alphabet a statute is written in. Every YAML writer in the encoder's repair paths serialized with `allow_unicode` false — explicitly at 107 call sites and by omission at 14 more — so the moment any auto-repair rewrote a generated module its summary, proof excerpts and rule sources turned into `\uXXXX` sequences. On a Hebrew, Amharic or Greek module that is the entire text: the encoding stops being readable next to the provision it encodes, which is what a verbatim proof excerpt is for, and nothing is gained, since the YAML is read back by a parser. For an ASCII module the flag is a no-op. Separately, a model asked for a non-Latin provision sometimes writes its own YAML that way, so overlay validation now rewrites `\uXXXX` escapes of non-ASCII characters back to the characters themselves in the generated module and its companion test, before the validation snapshot binds those bytes — and only when both forms parse to the same value, so a file the rewrite cannot prove equivalent is left exactly as the model wrote it.
