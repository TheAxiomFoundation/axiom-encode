The encoder guard's read-only git queries no longer capture Git's graft-file deprecation advice outside the verification runtime. Their environment sets `GIT_GRAFT_FILE=/dev/null`, which is itself a readable graft file, so every query that parsed a commit (`rev-parse --verify <sha>^{commit}`, `rev-list`, `merge-base`) wrote an eight-line `hint:` block to its stderr, with or without repository grafts. The environment now also sets `advice.graftFileDeprecated=false`, as the runtime's trusted git wrapper already does.
