The read-only git queries that run with `_read_only_git_environment()`, which include the guard's encoder identity and producer-admission checks, no longer capture Git's graft-file deprecation advice outside the verification runtime. That environment sets `GIT_GRAFT_FILE=/dev/null`, which is itself a readable graft file, so each of those queries that parsed a commit (`rev-parse --verify <sha>^{commit}`, `rev-list`, `merge-base`) wrote Git's `hint:` block to its stderr (eight lines with Git 2.54), with or without repository grafts. The environment now also sets `advice.graftFileDeprecated=false`, as the runtime's trusted git wrapper already does.
