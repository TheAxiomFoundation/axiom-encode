Numeric grounding now reads a pipe-table column headed with the Hebrew percent noun ("אחוזים מההכנסה", "הניכוי ... באחוזים") as a percentage column, so a bare 1.40 in it grounds the rate 0.014. A number inside a structural component (a section, paragraph or item reference such as "337(א)", "§ 12", "Nr. 3") keeps its structural typing even inside a percent column, in any language, instead of being retyped as a rate. In a pipe block that nowhere looks bordered (the first line neither begins nor ends with a pipe, and no later line begins and ends with one or has a leading pipe that, counted as a cell, would make the line wider than the table), a later row's leading pipe now marks an empty first cell when that keeps the row at the table's width (`| סך הכל | 14.50`), instead of shifting the row's values one column left; a table in which any line looks bordered reads as before.
