Add `axiom-encode triage-evidence`, which builds a deterministic, bounded failure-triage evidence bundle (`axiom-encode/failure-triage-evidence/v1`) for one failed run (a workflow failure bundle or a local run directory; `--batch` writes `evidence.jsonl` for a directory). The bundle holds the target and its source, the final candidate, the final-attempt issues with gate and bracket tag, the attempt history and five probes: the pre-encode gate in report mode, a registry probe (does a RuleSpec module export each import, deferral provider and registered input at the run's RuleSpec ref), a corpus probe, an import probe (compile error in the target's own file or in another module) and a persistence probe. No model is called and encode behaviour does not change.
