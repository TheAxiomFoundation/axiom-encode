Take generated test values from each input's declared dtype before guessing from its name or formula. Boolean and Judgment inputs get false, numeric dtypes (Money, Rate, Decimal, Integer, Count and Float) get 0, and String and Text inputs get an empty string. The auto cases, the apply-time wrong-typed repair and both missing-input fills read the declaration. An undeclared input also counts as numeric when a numeric rule returns it bare or passes it to min, max, abs, round, floor or ceil.
