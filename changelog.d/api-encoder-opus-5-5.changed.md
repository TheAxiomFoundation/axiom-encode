Default the Claude API encoder backend (`AgentSDKBackend`) to Claude Opus 5.5 at `high` effort (was Claude Opus 4.6), streaming with a 64,000-token budget because Opus 5.5 thinks adaptively and thinking counts against `max_tokens`. A refusal, a response cut off at `max_tokens` or at the model's context window, or a reply with no RuleSpec text is now a failed encode instead of a partial or empty RuleSpec, and thinking blocks never enter the output. A file already at the output path from an earlier run no longer overrides the model's reply. API encodes now report `cost_usd` and a `trace` (provider, backend, model, stop reason, effort, and a refusal's category), keep the usage on failed encodes, and close their HTTP client after each call. A refusal is priced by Anthropic's billing rules. Before any output it is billed in the `bio`, `frontier_llm` and `reasoning_extraction` categories and free in `cyber`, `general_harms` or a null category; after any output it is billed normally. It is unpriced (`cost_usd` of `None`) when it came before any output without `stop_details` or in a category Anthropic's billing table does not list. The refusal category is read from the stream's `message_delta` event, because anthropic 0.83.0 drops `stop_details` from the final message. `AXIOM_API_ENCODER_EFFORT` overrides the effort (a blank `effort` argument defers to it); an unknown effort raises `ValueError` when the backend is built. The `api` extra now requires `anthropic>=0.83.0`, the version `uv.lock` pins, whose `messages.stream` accepts `output_config`; on the old `>=0.40.0` floor an SDK without it failed every API encode with a `TypeError`. Pricing rates v5 add Claude Opus 5.5 and Claude Sonnet 5.5 from Anthropic's pricing page, captured 2026-09-28.
