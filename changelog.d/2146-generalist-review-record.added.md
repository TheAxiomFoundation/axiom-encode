Record the generalist review of each model-manifest unit in `encode --apply` and let a run require it (#2146). The encode outcome carries a `generalist_review` record with a status (`passed`, `partial`, `failed`, `unavailable` or `skipped`), the reviewer backend and model when the encoder knows them, a finite score, the review prompt digest, byte and canonical-content digests of the reviewed and applied files, and whole-file coverage of every file that manifest applies. The record compares YAML node trees and skips only the two `module.source_verification` keys that apply stamps; if the stamp's dump changes that digest, the record says `unavailable`. The signed apply manifest carries the record when the target's protected base sets `encoder_verifier = "main"` with no `encoder_verifier_hold`, and every apply reads that setting, so a malformed one can block manifest writing without the flag. `encode --apply --require-review` refuses to apply unless the record says `passed`, the manifest writer checks again before signing, and the flag refuses legacy replacements that rewrite exact dependents. The flag defaults to off.
