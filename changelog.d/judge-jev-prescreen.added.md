Add a TypeSafe System One (Jev) pre-screen ahead of the statutory-fidelity referee. The new `statutory_fidelity_screen` judge stage sends the same provision window and artifact as a typed state, asks one pass/flag choice plus one probability per fidelity finding kind, and emits an advisory `JudgeEvent` whose findings carry the kind and probability with empty locators (System One returns probabilities only, so no clause reference or rule path is fabricated). A configurable cascade policy is advisory by default; `AXIOM_JUDGE_SCREEN_MODE=cascade` lets a screen whose amount and boundary probabilities sit below the threshold record itself and skip the referee, while an errored screen always requests it. `judge-fidelity --screen` runs the screen first and `judge-fidelity-screen` runs it alone. The cross-family guard learns the `typesafe` family (model ids starting with `jev`), the optional `typesafe` extra pins `typesafe-sdk==0.6.0`, and the default threshold is a documented placeholder that the verifier track (#1657, landing under `benchmarks/verifier/`) must replace (`docs/judge-stages.md`).
