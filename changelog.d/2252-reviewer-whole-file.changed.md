Review a candidate that does not fit one generalist reviewer call in ordered chunks, and let the promotion lane require the review (#2252). One call still shows at most 6,000 characters of the module, 3,000 of the companion test file and 4,000 of the source excerpt; a candidate within those limits gets the same single prompt as before. A larger candidate is cut at root-level YAML entries (a rule, a test case) and at source paragraphs, never inside a line, into chunks of up to 24,000 characters. Every call must return its own `passed: true`; one failed call makes the review `failed`, and one call without a readable verdict makes it `unavailable`. At most 8 chunks for one text and 12 calls for one unit are made; above a cap the reviewer makes its one call on the start of each file and the record is `partial`. The `generalist_review` record is now `axiom-encode/generalist-review/v2`: a `coverage` block holds the call counts and the byte range and SHA-256 of every chunk, a file is `complete` only when its chunks cover the reviewed bytes exactly once, and a review that saw a part of the source excerpt is `partial` (`review_saw_truncated_source`). `promote-reviewed-candidate --require-review` runs the generalist reviewer on the exact candidate bytes after validation and signs only when the record is `passed`; the flag defaults to off, and without it the promotion runs no reviewer. Each call names the texts it shows whole and in part, and a call that shows everything says that it is the whole review. The outline of a module with several chunks lists imports, units, inputs and rules in a marked data block, and shows a value that is not a plain identifier as a placeholder with its digest. The record binds the digest of the reviewed source excerpt (`reviewed.source_sha256`), and a reader recomputes the planned call count from the chunk counts. `promote-reviewed-candidate --review-record-file` with `--run-attempt` writes the review record of a promotion, passed or refused, to a new JSON file; the signed promotion manifest still does not carry it (#2319).
