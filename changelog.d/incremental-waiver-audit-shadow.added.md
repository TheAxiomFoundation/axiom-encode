Add a report-only shadow of the incremental waiver audit: `validation-waivers audit --scope full --incremental-shadow-report <file>` runs the full audit unchanged, then computes the incremental selection of the same partition and writes a JSON comparison (`agree`, `incremental_missed`, `incremental_extra` or `inconclusive`). Malformed input, a failed selection or an incomplete full audit gives `inconclusive`. `--incremental-shadow-summary <file>` appends one Markdown line, and the record is also written to standard error. The option is off by default and never changes the audit report or exit code. See `docs/validation-waiver-audit-scope.md`.
