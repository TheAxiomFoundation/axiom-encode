A printed number flush before a plural or construct fraction word is its count ("3 עשיריות האחוז" is 0.003, "ל־3 רבעי השכר" 0.75); a spelled count is set aside only where the numeral grammar reads it and the fraction word as one mixed number, so "מאה ועשרים עשיריות האחוז" is 0.12 while "עשרים ושלוש עשיריות" stays 20.3; a number before a singular fraction word is no count; the percent sign after a spelled number binds across wrap space only, so "דרגה חמישית" before a blank line and "%" stays a fifth grade.
