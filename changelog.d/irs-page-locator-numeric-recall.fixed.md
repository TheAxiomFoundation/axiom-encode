Stop complete-source numeric recall from demanding the printed page number on the first line of an IRS revenue procedure or notice page source (`us/guidance/irs/{rev-proc,notice}-YYYY-N/page-N`). Since 0.2.2217 the extractor no longer treats a lone number on a line as structural, so these pages demanded their own page index. Only a first line that is exactly the citation's page number, followed by a blank line, is masked; a number followed by a single line break (where a unit may wrap onto the next line), any other leading number, and the same value later on the page stay demanded.
