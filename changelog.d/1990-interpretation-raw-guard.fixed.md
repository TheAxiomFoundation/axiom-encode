The raw interpretation YAML guard now runs on every RuleSpec document and closes four gaps. It rejects YAML merge keys that supply `module` or `module.interpretations`, since the engine does not apply merge keys and would read different interpretations from the encoder. It reports a duplicate root `module` key, where loading kept only the last block and apply stamping dropped the first. It rejects a `!!set` tag on the root or `module` mapping, which made PyYAML load the mapping as a set and skip validation while the engine still read it. It also reads a `!!str` tag on the first key of an interpretation mapping as the key's tag, rather than rejecting it as a collection tag.
