Require a code-owner review for every change under `.github/`, not only the five workflow files that `CODEOWNERS` named: the new `/.github/` entry gives an owner to the other 12 workflows, the pull request template and any workflow or action added later (#2257; the complement that `docs/merge-guard-key-protection.md` proposes, and step C of its "Now" list). Before this, a new or changed workflow file outside the named five needed no review, so one account with write access could land a workflow that selects a key-bearing environment. Code owners also own the key-environment tripwire test and a new test that fails if any path under `.github/` loses an owner. No repository setting changes: last-push approval and environment reviewers stay admin steps.
