Add `axiom-encode manifest-audit`, which asserts that **every** committed encoding manifest matches the file it attests, and that no file carries more than one live manifest. `guard-generated` asks whether a changed file has *a* matching attestation, so a single good record satisfies it and any other record committed alongside goes unread; the audit asks the question an outside auditor would ask instead, over every manifest tree in the repo — including the `<jurisdiction>/.axiom/encoding-manifests/...` trees the guard does not enumerate. It is deliberately schema- and signature-agnostic: signature and schema validity are the guard's job, and gating on schema would make the audit skip exactly the legacy records where stale claims accumulate. Claims that cannot be deleted without destroying a still-true sibling claim are disclosed in `.axiom/encoding-manifest-supersessions.yaml`, a ledger that attests nothing and whose every field is re-derived from the repository and from git history before it is accepted (axiom-encode#1282).
