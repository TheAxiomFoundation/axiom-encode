Resolve corpus sources from a bounded per-release cache: each `LocalCorpusRelease` reads, verifies, and parses a jurisdiction/document-class bucket once, indexes its citation paths, and memoizes resolution outcomes and parent compositions, including failures, while per-call read limits and on-disk dependency re-hashing still apply. A cached bucket is dropped and read again when any of its provisions files, or a lock that pins one, changes on disk. Validation fetches each cited provision once per module, staleness checks re-read the checkout, and release-object verification groups source artifacts by scope in one pass. N resolutions in an R-row bucket now read the bucket once and parse R rows instead of N reads and N × R parses; see `docs/corpus-resolution-cache.md`.
