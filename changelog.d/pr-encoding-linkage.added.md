Every pull request body now carries an `Encoding-Target:` line (corpus citation paths, or `none`) and a `Fixes-Run:` line (targeted-signed-reencode run ids, `local:<encoding_runs id>`, or `none`). The new `PR linkage` workflow checks them with `axiom_encode.pr_linkage` on every pull request open, edit and push, verifies each signed run id through the GitHub API (it must be a `targeted-signed-reencode.yml` run whose citation the PR lists, failing closed on lookup errors), and exempts the encoder version-bump App. `.github/pull_request_template.md`, `AGENTS.md` and `CLAUDE.md` tell authors and agents to fill both lines from the run they fix.
