`axiom-encode ci` supports validate-rulespec pins 0effa6a5 and 6f11be26, which rulespec-us uses, by executing the pinned workflow's own inline scripts from byte-exact packaged copies. It resolves dependency refs through a reviewed workflow-toolchain resolver and registry inputs from repository variables, and mirrors the shard matrix, partitioned waiver audits and the supervisor's empty child environment. Like a pull_request run, it validates GitHub's test merge when HEAD lacks the base, in a checkout named after the base repository, on a UTC clock. New flags: `--corpus-release-retired-public-key`, `--apply-public-key`, `--eval-public-key`, `--corpus-release-registry-url`, `--corpus-release-registry-anon-key`, `--pull-request`, `--github-repository`, `--base-branch` and `--jobs`.
