Add the real-defects verifier corpus (`benchmarks/verifier/real_defects_v0`): 171 triaged cases of real encoding defects taken from the `rulespec-us` and `rulespec-uk` fix history, one per correction, each pairing the pre-fix and post-fix module bytes with provision text resolved from a signed corpus release selected from the fix commit's toolchain pins (the README gives the selection rules). Every case records whether a judge can decide it from that provision (`judgeable_from_provision`, with the decisive passages quoted and located): two readers checked each case, and where the decisive text sat under another of the module's citations the provision was extended with it. The corpus ships its triage record, the build tools, `scripts/verify_real_defects.py` to re-derive every digest from Git and the release registry, and tests. The verifier track's `build-real` loader now leaves out, by default, cases marked not judgeable and cases whose decisive text falls outside the provision window (`--include-not-judgeable` keeps them).
