Live-run telemetry is now on by default for every encoder, credential-free: environments without Supabase write credentials report run presence to the public ops ingest endpoint (`axiom-foundation.org/api/ops/encoding/ingest`), where rows are server-stamped as self-reported. Credentialed environments keep writing directly as trusted telemetry. Opt out with `--no-sync` or `AXIOM_ENCODE_TELEMETRY=off`; override the endpoint with `AXIOM_ENCODE_TELEMETRY_INGEST_URL`. The CI signed-encode workflows no longer pass `--no-sync`, so CI runs appear on the ops dashboard live.
