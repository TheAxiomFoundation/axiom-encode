Add `axiom-encode compare-sources` (package `axiom_encode.source_conflicts`, runbook `docs/source-conflict-compare.md`): the compare step for source conflicts (#2150). A link file names the rules of two RuleSpec modules that decide the same question and maps the shared facts to each module's inputs. The step validates the link, checks it against both compiled artifacts (every output, guard and input resolves; every input the compared rules read has a supplier; kinds match how the rules use an input; no constraint removes every combination), takes fact values from the modules' own thresholds with the value just below and above each one, runs both modules in the engine the RuleSpec repository pins, and writes a versioned, byte-stable conflict record: the households for which the two sides differ, grouped, with the proof atoms of the deciding rules on both sides and `review_state: unreviewed`. No encoder prompt, validation gate or Supabase table changes.
