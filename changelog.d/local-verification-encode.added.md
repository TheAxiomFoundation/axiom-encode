`encode --corpus-release-public-key` (with optional `--corpus-release-retired-public-key`, `--apply-public-key` and `--eval-public-key`) runs a verification-only local encode: the pinned corpus release is verified with these public roots instead of an attached signing broker, as `axiom-encode ci` does. It conveys no signing capability, refuses `--apply`, and refuses to start under an attached signing broker, the trusted runtime or CI.
