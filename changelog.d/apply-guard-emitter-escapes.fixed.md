Keep the escapes PyYAML's emitter writes itself, such as those for U+FEFF, U+2028 and U+2029, when rewriting a generated module's non-ASCII escapes. Apply stamps the module again before it checks the validated bytes, and that stamp escaped a rewritten U+FEFF again, so apply refused a module that overlay validation had passed. When apply refuses, it now names the snapshot fields that changed, such as `output.sha256`, and never their values.
