`axiom-encode encode` now announces itself to the ops dashboard while running: each invocation inserts a row into the new `encodings.live_encoding_runs` table at start (with machine identity — hostname, username, platform, CI flag), heartbeats it every 30 seconds, and closes it with the final `encoding_runs` id. Concurrent encodes across machines are now visible in real time, and a stale heartbeat on a `running` row surfaces encoder crashes. Telemetry is best-effort and never fails an encode (migration `006_live_encoding_runs.sql`).
