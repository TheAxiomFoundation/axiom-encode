The coordinated-quantity guards read each endpoint with the numeral grammar inside an atomic group, so teens ("שלושה עשר"), compounds ("עשרים ואחד") and spelled conjunctions ("שתיים ושלוש") are read once and never re-partitioned; only the supplement noun "תוספת" takes the comma-allowed list of amounts, so "סעיף 5, 2 או 3 אחוזים" keeps section 5; the percentage walk-back stops before a section, an age or a year ("לילד עד גיל 5, 2 או 3 אחוזים" keeps the age); and only a unit of time opens a temporal phrase, so "עשירית שקל לאחר הגשת הבקשה" is a tenth of a shekel in any wording.
