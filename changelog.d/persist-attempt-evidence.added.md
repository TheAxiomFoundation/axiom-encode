Every encode attempt now persists the evidence that makes a failed generation a labeled case: the validator's structured issue list (gate, kind, message, locator, line, value, clause) inline in `iterations_json`, `encode_issue` events, and repair manifests; the attempt's RuleSpec and companion-test text in `artifact_versions` and `run_artifacts` with its SHA-256, attempt label, and validator outcome; `parent_run_id` on regenerations of the same citation (explicit `--parent-run-id` or `AXIOM_ENCODE_PARENT_RUN_ID`, else the most recent finished run in the same database); and judge verdicts in a new `judge_events` table mirrored from the run log. `axiom-encode attempt-evidence-backfill` migrates an existing database in place and backfills parent links, final-attempt artifacts, and judge events from run-log JSONL; `axiom-encode attempt-evidence` and the exported `axiom_encode.attempt_evidence` helper read `(run_id, attempt, artifact, issues, parent)` records without writing.
