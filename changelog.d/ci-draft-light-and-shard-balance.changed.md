A draft pull request's CI runs only `lint` and a `quick tests (draft)` job over the `tests/test_*.py` files it changes; its `test (3.13)` check fails, also when a pull request is turned back into a draft, until the pull request is marked ready, which starts the full run. `gh workflow run CI --ref <branch>` runs the full suite on a branch. `test (3.13)` now also needs `real-engine` to pass in the same run. The CI shards keep tests that share a module- or class-scoped fixture in one shard and split the cases of a parametrized function whose `tests/ci_shard_seconds.json` entry reaches 180 seconds; the table is refreshed from main's CI run of 2026-11-03.
