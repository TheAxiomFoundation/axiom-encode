A draft pull request's CI runs only `lint` and a `quick tests (draft)` job over the `tests/test_*.py` files it changes; its `test (3.13)` check fails until the pull request is marked ready, which starts the full run, or a full run is dispatched with `gh workflow run CI --ref <branch>`. The CI shards keep tests that share a module- or class-scoped fixture in one shard and split the cases of a parametrized function whose `tests/ci_shard_seconds.json` entry reaches 180 seconds; the table is refreshed from main's CI run of 2026-11-03.
