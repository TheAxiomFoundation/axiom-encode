The two jobs that select a key-bearing environment, `targeted-signed-reencode.yml`'s `encode` (production signing) and `finalize-signed-snap-queue.yml`'s `finalize`, no longer restore or save the uv cache. `setup-uv`'s default, `enable-cache: auto`, turns the cache on for hosted runners, and an entry under the same key can be written by any run on `main`, so a cached build reached the signing job's installs. `tests/test_workflow_toolchain_pins.py` now fails if a job with an environment uses `setup-uv` without `enable-cache: "false"`, `setup-go` without `cache: false`, a caching `setup-python`, or `actions/cache`.
