Place a pinned corpus release's provisions in a corpus checkout that keeps its bytes outside git. When `LocalCorpusRelease` binds a checkout with `.axiom/corpus-locks/`, it verifies the signed release object and then places each missing provisions artifact. Each file comes from the first of these sources whose bytes hash to the release's sha256 and byte count: the `axiom-corpus-ingest` content cache, the file at the release's git commit, the lock file's `git_blob`, or the release's R2 bucket by sha256 key. Placement fails closed and never replaces or links a file. Checkouts without lock files are unchanged. `axiom-encode corpus-fetch` does the same explicitly, and supervised CI reads from git objects through the trusted wrapper (docs/corpus-bytes-outside-git.md).
