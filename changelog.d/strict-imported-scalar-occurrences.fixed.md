Credit an explicitly imported parameter in the complete-source-unit numeric-occurrence check. The check dropped the `#symbol` suffix of each import before it looked for one, so it never counted an imported scalar and reported "0 named scalar definition(s)" for a source number that the module imports as a named parameter, while typed numeric recall accepted the same import. The check now reads the import items with their symbol and counts only a direct scalar definition of that exact symbol in the resolved file. An import of a symbol with a different value, a file-level import without a symbol, an unresolved target, and a number with no parameter are still refused.
