Add a shadow "independent (blind) test author" (`scripts/blind_test_author.py`, library `axiom_encode.blind_test_author`, runbook `docs/blind-test-author.md`). A second model, through the local `claude` subscription CLI, writes test cases from the corpus source text and the module's declared interface only (names, entities, dtypes, periods, units); it never sees formulas, parameter values, effective dates or the encoder's companion tests, and a guard refuses any prompt that would carry them. Each case quotes the source sentence that justifies it; a case whose sentence is not verbatim in the source text is rejected. The cases run through the companion-test runner on the real rules engine, and the tool reports agree / disagree / not-runnable per case as JSON and text. It declares no validation check, is not called by `encode`, and changes no validation result.
