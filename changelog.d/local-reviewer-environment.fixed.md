Give local (no signing broker, non-CI) runs a working reviewer environment: the generalist reviewer CLI now starts with an explicit allowlist (account home and user, per-user TMPDIR, PATH limited to the resolved reviewer binaries plus system directories) instead of an empty PATH and `HOME=/nonexistent`. A reviewer that cannot start is reported as `reviewer_unavailable`, printed as `generalist_review=error`, and recorded as a failed review instead of being dropped. Protected and CI runs keep the existing sandboxed reviewer environment unchanged.
