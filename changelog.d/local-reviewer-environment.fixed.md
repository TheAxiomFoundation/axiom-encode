Give the verification-only local encode a working reviewer environment: only inside that context (no signing broker, no trusted runtime, not CI), the generalist reviewer CLI starts with an explicit allowlist (account home and user, per-user TMPDIR, `CODEX_HOME`/`CLAUDE_CONFIG_DIR`, and a PATH of the resolved reviewer binary's directories, the interpreter its `#!/usr/bin/env` shebang names, and the system directories) instead of an empty PATH and `HOME=/nonexistent`. A reviewer that cannot start is reported as `reviewer_unavailable`, printed as `generalist_review=error`, and recorded as a failed review instead of being dropped. Every other run, including any run with a signing broker attached, keeps the existing sandboxed reviewer environment unchanged.
