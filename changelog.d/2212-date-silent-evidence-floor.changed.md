A corpus manual unit that prints no date no longer takes its start date from a neighbouring module (#2212). For manual units without amendment context, the encoder prompt now states the start-date rule: a printed date, the evidence floor (first day of the first full calendar month on or after `source_as_of`; an evidence-coverage floor, not a claimed legal commencement date), the corpus `expression_date` or `source_as_of`, or the `0001-01-01` scaffold; the prompt of every other document class is unchanged. The new complete-source check `complete-source-unit:effective-date/start-unsupported` refuses any other `effective_from` in such a unit, except a version start of an imported export. It runs only in complete-source mode (new encodes and promotions), so `validate` on existing modules is unchanged.
