Make the `gates-collapsed` check advisory (issue #2300). A check now declares its `enforcement`: `blocking` (the default) or `advisory`. A finding of an advisory check is still computed, recorded with the same detail and shown to the reviewer as a warning to examine, but it does not refuse a candidate by itself and it does not start a feedback retry by itself. Only `complete-source-unit:source-explicit-conditions/gates-collapsed` is advisory; every other check blocks as before, and an unknown `enforcement` value is an error. A real collapse of source conditions into too few inputs is no longer refused automatically by this check.
