Central encode queue, first milestone: `axiom-encode queue add|move|package|build|status|claim|heartbeat|release|report|apply` (module `axiom_encode.encode_queue`). One shared list of (program, jurisdiction) packages and their units, with an atomic claim and an expiring lease per unit, so several machines never encode the same unit. Unit membership is derived from the program bundle, the pinned corpus, RuleSpec main and open candidate pull requests. Backends: a local directory, and a branch of a GitHub repository written with one expected-head commit request per batch (needs only the `gh` login). Lease time is the store's time; every queue document is validated on read and the RuleSpec target path is always computed from the citation; worker requests can be sent again safely. Nothing calls it yet: no runner, workflow, admission or signing path reads the queue.
