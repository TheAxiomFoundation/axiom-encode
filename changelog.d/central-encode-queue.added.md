Central encode queue, first milestone: `axiom-encode queue add|move|package|build|status|claim|heartbeat|release|report` (module `axiom_encode.encode_queue`). One shared list of (program, jurisdiction) packages and their units, with an atomic claim and an expiring lease per unit, so several machines never encode the same unit. Unit membership is derived from the program bundle, the pinned corpus, RuleSpec main and open candidate pull requests. Backends: a local directory, and a branch of a GitHub repository moved by a fast-forward-only reference update (needs only the `gh` login). Nothing calls it yet: no runner, workflow, admission or signing path reads the queue.
