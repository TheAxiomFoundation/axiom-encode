# Retired source metadata replacement admission

`encode --replace-rulespec-path` retains the original module as generation context. It may admit retired plural module source metadata as historical input; generated output still requires singular source metadata and all normal proof, compilation, completeness and companion validation.

Contained descendants must resolve within the same verified release, artifact and source scope. Matching permits only exact text or whitespace folding within one parent evidence segment. Reports retain child byte hashes and raw parent character offsets. A whitespace-folded match also records `unicode-whitespace/v1` and its normalized text hash; replay by folding whitespace in the child and recorded parent slice. Words, punctuation, source versions and provenance cannot be normalized away.

A separate `retired-source-external-parameters/v1` input contract admits an external citation only when it resolves exactly, without composed rows or slicing, in the same verified release and jurisdiction. Every occurrence of that citation must belong to a formula proof on a uniquely named, single-version, literal numeric parameter. The excerpt must occur in a verified evidence segment. Top-level proof layouts and other uses are rejected by this bounded contract.

The entire externally proved legacy rule must remain unchanged, including its formula, dates, unit and proof. The apply overlay checks that obligation both before normal validation and after all automatic repairs, immediately before recording the successful validation snapshot. The signed output bytes therefore include the preserved proof and parameter. This does not authorize arbitrary external derived rules, imported replacements, or changes to those parameters.

`retired-source-admission.json` retains the original YAML hash, every resolver attestation and unchanged-rule obligations. Workflow packaging checksums the report for review. This diagnostic report does not replace signed provenance or output validation. Unsupported legacy source combinations remain blocked for a separate migration design.
